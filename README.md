# Seasonals-VP200-OLR-Tropical-Waves-Forecasts
This repository contains a first-of-its-kind codebase for seasonal forecasts of tropical wave propagations, VP200 &amp; OLR anomalies derived using ECMWF seasonal forecasts dataset. It include both Hovmöller diagram construction as well as global map based presentation. Historical hindsight plots are derived using ERA5 dataset
